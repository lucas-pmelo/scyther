# Scyther

Sistema de processamento de vídeos — Hackathon FIAP Pós-Tech, Fase 5.

Recebe vídeos, extrai frames e entrega um `.zip`, reconstruindo o protótipo do enunciado com
arquitetura de microsserviços, mensageria, observabilidade e CI/CD.
